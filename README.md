# CCNP 从小白到专家 · 系统化学习资料

> 一份为「真的想学会网络」而不是「只想过考试」的人准备的中文学习资料。
> 主线 **CCNP Enterprise（ENCOR 350-401 + ENARSI 300-410）**，附 Security 选修模块。
> 所有配置命令给出 **Cisco / H3C / 华为** 三厂商对照 —— 因为国内多数人上班用国产设备，考试却考 Cisco。

---

## 这份资料解决什么问题

大多数 CCNP 资料有两个通病：

1. **按考纲平铺**。第 3 章讲 OSPF，第 5 章讲 BGP，两章之间毫无关系。可真实网络里出问题的地方，恰恰是「OSPF 学到的路由重分发进 BGP 之后，为什么回不来了」这种**协议交互**。
2. **只给命令，不给症状**。`show ip ospf neighbor` 大家都会敲，但邻居卡在 `EXSTART` 该查什么、卡在 `2-WAY` 是不是故障，没人讲。

所以这份资料的组织方式是 **单协议 → 协议交互 → 排障方法论** 三层递进，每一章都必须回答"这玩意儿到底解决什么业务问题"。

## 每一章长什么样

统一六段式结构，缺一不可：

```
① 这章解决什么问题   —— 从一个真实业务场景切入，不上来就甩定义
② 原理讲透           —— 图 + 报文格式 + 状态机，讲到能自己推导为止
③ 配置命令           —— Cisco 主线 + H3C/华为 对照
④ 配套实验           —— 拓扑 / 分步配置 / 验证命令 / 预期输出
⑤ 排障思路           —— 症状 → 怀疑点 → 验证命令 → 根因
⑥ 考点提示 + 自测题  —— 含答案与解析
```

## 怎么用这份资料

**如果你是纯小白**：从 `00-基础篇` 第 1 章开始，按序号走。不要跳。第 3 章子网划分务必手算到熟练，这是后面一切的地基。

**如果你有 CCNA 水平**：直接从 `01-CCNA补齐篇` 快速扫一遍确认没有盲区，重点做每章的自测题，错了再回头看。然后进 `02-ENCOR`。

**如果你已经在做网络运维（用 H3C/华为）**：先看 [`07-附录/03-Cisco-H3C-华为命令对照.md`](docs/07-附录/03-Cisco-H3C-华为命令对照.md) 建立映射，再从 `02-ENCOR` 切入，把已有经验挂到 Cisco 术语体系上。ENARSI 的排障章节对你日常工作价值最大。

**通用建议**：

- **每章必做实验**。看懂 ≠ 会配 ≠ 会排障。三者之间各隔着一条鸿沟，只有敲键盘能跨过去。
- **维护一份自己的错题本**。这份资料的自测题错了什么，记下来，两周后重做。
- **别追求一次学完**。ENCOR 的自动化和 SD-WAN 章节第一遍读不懂很正常，先过，学完路由再回头。

## 实验环境

| 方案 | 成本 | 说明 |
|:--|:--|:--|
| **Cisco CML 2.x**（推荐） | 官方付费 | 官方镜像，行为最接近真机，考试模拟度最高 |
| **EVE-NG Community** | 免费 | 生态最好，镜像获取方便，本资料实验以此为基准 |
| **PNETLab** | 免费 | EVE-NG 分支，自带实验商店 |
| **GNS3** | 免费 | 老牌方案，二层特性支持较弱（STP/VLAN 需配 IOU/IOL） |
| **Packet Tracer** | 免费 | 只够 CCNA，**不要用它学 CCNP**（BGP/MPLS/组播 支持残缺） |

搭建步骤见 [`04-实验手册/00-实验环境搭建.md`](docs/04-实验手册/00-实验环境搭建.md)。
