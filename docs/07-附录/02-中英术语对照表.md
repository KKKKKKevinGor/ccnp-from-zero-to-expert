## ⑯ ★ 考试高频英文表述 ★

**题干里常见的说法，看到就要秒懂**：

| 英文表述 | 含义 |
|:--|:--|
| "Which command **verifies**...?" | 哪条命令**验证**…？（问 show 命令） |
| "Which configuration **achieves**...?" | 哪个配置**实现**…？ |
| "What is the **effect** of...?" | …的**影响/后果**是什么？ |
| "**Refer to the exhibit.**" | ★ **参考图示**（一定要仔细看配置/输出） |
| "**Drag and drop** the ... from the left onto the ... on the right" | 把左边的拖到右边（拖拽题） |
| "**Which two** ...? (Choose two.)" | ★ **哪两个**（多选，必须选够数量） |
| "An engineer **must configure**..." | 工程师**必须配置**… |
| "**Troubleshoot** the issue" | 排查这个问题 |
| "The link is **flapping**" | 链路在**反复 up/down** |
| "Routes are **not being installed**" | 路由**没有装入路由表** |
| "The neighbor **is stuck in** EXSTART" | 邻居**卡在** EXSTART |
| "**Traffic is black-holed**" | 流量**进了黑洞** |
| "**Suboptimal routing**" | ★ **次优路由** |
| "**Asymmetric routing**" | ★ **非对称路由** |
| "**Intermittent** connectivity" | ★ **间歇性**连通问题 |
| "The path is **not preferred**" | 这条路径**不被优选** |
| "**Which two** are **prerequisites**?" | 哪两个是**前提条件**？ |
| "**Least** / **Most** administrative effort" | **最少** / **最多**的管理工作量 |
| "**Without** disrupting..." | 在**不中断**…的情况下 |
