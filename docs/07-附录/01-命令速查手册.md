## ② L1 物理层

```cisco
! ── 快速扫描 ──
show interfaces status
show interfaces status err-disabled
show interfaces description

! ── 错误计数 ──
show interfaces <接口> | include error|drop|rate|collision
show interfaces counters errors
clear counters <接口>

! ── 光模块诊断 ──
show interfaces <接口> transceiver detail
show interfaces transceiver

! ── err-disable ──
show interfaces status err-disabled
show errdisable recovery
errdisable recovery cause bpduguard          ! 配置自动恢复
errdisable recovery interval 300

! ── 速率双工 ──
show interfaces <接口> | include duplex|Duplex|Speed
```

**★ 关键判读**：

| 现象 | 含义 |
|:--|:--|
| `notconnect` | 物理未连接 |
| `err-disabled` | 被保护机制关闭 |
| **`inactive`** | ★ **VLAN 不存在** |
| `disabled` | 被 shutdown |
| **`late collision` > 0** | ★ **双工不匹配** |
| **`CRC` 增长** | ★ **物理层质量**（线缆/光模块/干扰） |
| **`output drops` 增长** | ★ **拥塞** |
| Rx Power < -25 dBm | 光衰过大 |

## ③ L2 链路层

```cisco
! ── MAC 表 ──
show mac address-table
show mac address-table address <MAC>         ! ★ 反复执行查震荡
show mac address-table interface <接口>
show mac address-table vlan 10
show mac address-table count
clear mac address-table dynamic

! ── ★ Trunk（四段输出法）★ ──
show interfaces trunk
show interfaces <接口> switchport

! ── VLAN ──
show vlan brief
show vlan id 10

! ── STP ──
show spanning-tree summary
show spanning-tree vlan 10
show spanning-tree mst
show spanning-tree mst configuration digest  ! ★ 验证 Region 一致性
show spanning-tree root
show spanning-tree blockedports
show spanning-tree inconsistentports
show spanning-tree vlan 10 detail | include occurr|from    ! ★ 找震荡源

! ── EtherChannel ──
show etherchannel summary                    ! ★ 看标志位
show etherchannel <组号> detail
show lacp neighbor
show lacp <组号> internal

! ── 风暴抑制 ──
show storm-control
```

**★ `show interfaces trunk` 四段输出法**：
```
   第 1 段：Native VLAN      ← 对比两端
   第 2 段：配置允许的       ← 没有 = 配置里没放行
   第 3 段：实际存在的       ← 没有 = VLAN 未创建
   第 4 段：真正转发的       ← 没有 = 被 STP 阻塞
   
   ★ 从第 4 段往上看，找到在哪一步被卡掉 ★
```

## ⑤ 路由协议

### OSPF
```cisco
show ip ospf neighbor
show ip ospf neighbor detail
show ip ospf interface <接口>                ! ★ 对比两端 5 个条件 + MTU
show ip ospf interface brief
show ip ospf                                 ! 进程信息、Router ID、参考带宽
show ip ospf | include Area                  ! 区域类型
show ip ospf database                        ! ★ 排障分界线
show ip ospf database router
show ip ospf database network
show ip ospf database summary
show ip ospf database asbr-summary
show ip ospf database external
show ip ospf database nssa-external
show ip ospf virtual-links
show ip ospf statistics                      ! ★ SPF 运行次数（查震荡）
show ip route ospf
clear ip ospf process                        ! ⚠️ 会中断所有邻居
debug ip ospf adj                            ! 邻接建立调试
```

### EIGRP
```cisco
show ip eigrp neighbors
show ip eigrp neighbors detail               ! ★ 看 Stub 和 Suppressing queries
show ip eigrp topology                       ! ★ Successor 和 FS
show ip eigrp topology all-links             ! ★ 所有路径（含非 FS）
show ip eigrp topology active                ! ★★ 巡检必查，正常应无输出
show ip eigrp topology <网段>
show ip eigrp interfaces
show ip eigrp interfaces detail
show ip eigrp events
show ip route eigrp
show ip protocols | include K1|summar        ! K 值和 auto-summary
show key chain                               ! ★ 认证密钥有效期
```

### BGP
```cisco
show ip bgp summary                          ! ★ 邻居状态和前缀数
show ip bgp                                  ! ★ 看标志位
show ip bgp <前缀>                           ! ★ 看选路原因
show ip bgp neighbors <IP>
show ip bgp neighbors <IP> advertised-routes ! 我发出去的
show ip bgp neighbors <IP> routes            ! 收到并通过过滤的
show ip bgp neighbors <IP> received-routes   ! ★ 原始收到的（需 soft-reconfig）
show ip bgp rib-failure                      ! ★ 巡检必查
show ip bgp regexp ^100$                     ! AS-Path 正则测试
show ip bgp community 65001:100
show route-map <名称>                        ! ★ 验证有没有兜底
show ip prefix-list detail <名称>            ! ★ hit count
clear ip bgp <IP> soft in                    ! ★ 软重置
clear ip bgp <IP> soft out
! ⚠️ 绝不要用 clear ip bgp *
```

**★ BGP 标志速查**：
```
   *   valid（下一跳可达）    没有 * = ★ 下一跳不可达 ★
   >   best（会进路由表）
   i   从 iBGP 学到
   r   ★ RIB-failure（AD 更低的路由抢赢了）★
   s   suppressed（被聚合抑制）
```

**★ IPsec 计数器诊断表**：

| encaps | decaps | 诊断 |
|:--|:--|:--|
| 涨 | 涨 | ✅ 正常 |
| **涨** | **0** | ❌ **对端问题** |
| **0** | 涨 | ❌ **本端问题**（路由/NAT） |
| 0 | 0 | ❌ 流量没进隧道 |

**★ `show dmvpn` 标志**：
```
   S = Static    D = Dynamic    N = NATed
   ★ X = No Socket（IPsec 未建立）★
   T1 = 路由已安装
```
