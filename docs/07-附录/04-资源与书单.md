## ② 书单

### ★ 官方认证指南（必备）

| 书 | 说明 |
|:--|:--|
| **CCNP and CCIE Enterprise Core ENCOR 350-401 Official Cert Guide** | ★ 官方教材，内容全面但偏枯燥。**当参考书用，不要从头读到尾** |
| **CCNP Enterprise Advanced Routing ENARSI 300-410 Official Cert Guide** | 同上 |

**★ 使用建议**：官方指南**不适合从零学习**（太厚太干），适合：
- 查某个知识点的完整描述
- 考前查漏补缺（对照考纲）
- 看它的 "Exam Preparation Tasks" 部分

### ★ 强烈推荐的深入读物

| 书 | 说明 |
|:--|:--|
| **Routing TCP/IP, Volume I & II**（Jeff Doyle） | ★★ **路由协议圣经**。想真正理解 OSPF/EIGRP/BGP 的原理，看这本 |
| **TCP/IP Illustrated, Volume 1**（Stevens） | ★★ 协议细节的经典，配合抓包看 |
| **Network Warrior**（Gary Donahue） | ★ 实战经验，讲很多书上没有的坑 |
| **The Practice of Network Security Monitoring**（Bejtlich） | 网络安全监控与抓包分析 |
| **BGP Design and Implementation**（Cisco Press） | BGP 深入 |
| **MPLS Fundamentals**（Luc De Ghein） | ★ MPLS 讲得最清楚的一本 |
| **802.11 Wireless Networks: The Definitive Guide** | 无线原理 |
| **Cisco ISE for BYOD and Secure Unified Access** | 802.1X/ISE 实战 |
| **Network Programmability and Automation**（O'Reilly） | ★ 网络自动化入门首选 |
| **Wireshark 网络分析就这么简单 / 实战详解**（林沛满） | ★ 中文，抓包分析入门极佳 |

### 中文书

## ⑧ ★ 学习路径建议 ★

### 主线（不要偏离）

```
   ★ 本教程 ★（系统化的知识框架）
        ↓
   ★ 实验手册 ★（动手 + 故障注入）
        ↓
   ★ 官方考纲对照 ★（查漏补缺）
        ↓
   ★ 排障方法论 ★（形成思维框架）
        ↓
   考试
```

### 辅助（按需查阅，不要当主线）

```
   □ 官方 Cert Guide      → 查某个知识点的完整描述
   □ Routing TCP/IP       → 想深入理解协议原理时
   □ NetworkLessons       → 某个概念看不懂时换个讲法
   □ 视频课               → 难点的辅助理解
   □ Cisco Config Guide   → 查具体命令语法
   □ RFC                  → 追根究底时
```

### ★ 三个反模式（避免）

```
   ✗ 1. 收集了一堆资料但不动手
        → 资料越多越焦虑，实际什么都没学
        ★ 一本主线教材 + 一个实验环境就够了 ★
   
   ✗ 2. 只看视频不做实验
        → 有"学会了"的错觉，一上手全忘
        ★ 看完必须立刻做实验 ★
   
   ✗ 3. 背题库
        → Cisco 会更新题目
        → ★ 违反考试协议，被查到取消所有认证 ★
        → 过了也不会用
```

## ⑨ ★ 拿证之后 ★

### 继续深入的方向

| 方向 | 下一步 |
|:--|:--|
| **路由交换深入** | **CCIE Enterprise Infrastructure**（ENCOR 就是笔试） |
| **数据中心** | CCNP Data Center（Nexus、ACI、VXLAN/EVPN） |
| **安全** | CCNP Security、CISSP |
| **自动化** | **DevNet Professional**、Python、Ansible、Terraform |
| **云** | AWS/Azure 网络认证、云网互联 |
| **无线** | CCNP Enterprise Wireless (ENWLSI) |
| **SD-WAN** | ENSDWI 300-415 |

### ★ 认证维持（3 年）

| 方式 | 说明 |
|:--|:--|
| 重考 ENCOR 或任一 Professional 考试 | 传统方式 |
| 通过 CCIE 笔试 | 顺便升级 |
| **★ CE 学分（80 分）★** | **推荐**。通过 Cisco Continuing Education 平台的在线课程、Cisco Live 会议等积累 |

### ★ 比证书更重要的

```
   ★ 1. 把学到的用在工作中 ★
      · 学了 NetFlow → 在公司出口部署一个
      · 学了 EEM → 写一个自动备份配置的脚本
      · 学了 QoS → 给公司的 VoIP 做优化
      · 学了排障方法论 → 下次故障按框架走
   
   ★ 2. 建立自己的知识库 ★
      · 故障记录（本教程的模板）
      · 实验笔记
      · 配置模板库
      ★ 三年后这些比证书值钱得多 ★
   
   ★ 3. 输出 ★
      · 写技术博客
      · 在团队内做分享
      · 参与开源项目
      ★ 教是最好的学 ★
   
   ★ 4. 关注方向的变化 ★
      · 传统路由交换的岗位在减少
      · 自动化、云网、安全在增长
      ★ CCNP 是基础，不是终点 ★
```
