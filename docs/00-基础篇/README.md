# Stage 0 · 基础篇

> **目标**：学完这一篇，你能在脑子里完整地跟踪一个数据包从"用户点了一下鼠标"到"对端服务器网卡收到"的全过程，并且知道每一跳设备对它做了什么。

## 为什么必须从这里开始

CCNP 的所有内容——OSPF 的 LSA 泛洪、BGP 的路径属性、VXLAN 的封装、QoS 的标记——都是在**已经理解封装和寻址**的前提下讲的。跳过基础直接学协议，结果一定是「命令会敲，一出问题就抓瞎」。

尤其是 **第 3 章子网划分**：如果你不能不用计算器、30 秒内算出任意一个 CIDR 的网络地址和可用范围，那么后面的 ACL 通配符掩码、路由汇总、OSPF 区域规划全都会卡住。这一章值得你花掉整个基础篇一半的时间。

## 过关自检

学完本篇，闭卷回答下面 6 题，全对再进 Stage 1：

1. 一台主机 ping 同网段的另一台主机，第一个发出去的以太网帧是什么？为什么？
2. 交换机收到一个目的 MAC 在自己表里没有的单播帧，会做什么？这个行为叫什么？
3. `172.16.30.0/22` 的网络地址、广播地址、可用主机范围分别是什么？（限时 30 秒，不许用计算器）
4. 路由表里同时有 `10.0.0.0/8`、`10.1.0.0/16`、`10.1.1.0/24` 三条，去往 `10.1.1.5` 走哪条？为什么？
5. TCP 为什么握手三次就够，挥手却要四次？
6. 在特权模式下敲了 `configure terminal` 改了配置，然后设备断电重启，配置还在吗？为什么？

答案分散在各章的「自测题」小节。
