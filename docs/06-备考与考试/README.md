# Stage 6 · 备考与考试

## 认证路径

```
   ★ ENCOR 350-401 ★（核心，必考）
        ↓
   获得：Cisco Certified Specialist – Enterprise Core
        ↓
   ★ + 一门选考 ★
        ├─ ★ ENARSI 300-410 ★ （高级路由，最主流）
        ├─ ENSLD 300-420  （设计）
        ├─ ENWLSI 300-430 （无线实施）
        ├─ ENAUTO 300-435 （自动化）
        └─ ENSDWI 300-415 （SD-WAN）
        ↓
   ★★ CCNP Enterprise 认证 ★★（有效期 3 年）
```

> **ENCOR 也是 CCIE Enterprise Infrastructure 的笔试。** 通过它就可以约 CCIE 实验考试。

## 考试信息

| | **ENCOR 350-401** | **ENARSI 300-410** |
|:--|:--|:--|
| 时长 | **120 分钟** | **90 分钟** |
| 题量 | 90–110 题 | 55–65 题 |
| 语言 | 英文 / 日文 | 英文 / 日文 |
| 通过分数 | **不公布**（约 750-850/1000） | 同左 |
| 费用 | 约 **$400** USD | 约 **$300** USD |
| 重考等待 | 首次失败等 **5 天** | 同左 |
| 有效期 | 3 年 | 3 年 |

> **注意**：Cisco 不公布通过线，且**每次考试的分数线可能不同**（按题目难度动态调整）。目标应该是"扎实掌握"，而不是"刚好及格"。

## 题型

| 题型 | 说明 | 占比 |
|:--|:--|:--|
| **单选/多选** | 概念、配置、故障判断 | ~70% |
| **拖拽（Drag & Drop）** | 概念配对、顺序排列 | ~10% |
| **模拟题（Sim）** | 在模拟的 CLI 里配置 | ~10% |
| **实验题（Lab）** | 完整场景的配置任务 | ~10% |

**★ Sim 和 Lab 题的注意事项**：
- **不能用 `?` 补全**（部分模拟器支持有限）
- **必须记住完整的命令语法**
- **配完要 `end`，有的题要求 `write memory`**
- **时间压力大**，先做选择题，把 Sim/Lab 留到最后（或者先做，看个人策略）

## ★ 备考策略

### 时间分配（在职学习，每天 1.5-2 小时 + 周末 4 小时）

```
   ENCOR：★ 10-12 周 ★
   ENARSI：★ 6-8 周 ★
   合计：★ 约 5 个月 ★
```

**如果时间紧张**：先集中攻 ENCOR，考过后再准备 ENARSI。**不要同时准备两门。**

### 三条硬性要求

```
   ★ 1. 实验必须做 ★
      Sim 和 Lab 题占 20%，纯看书不可能过
      而且实验能极大加深对概念的理解
   
   ★ 2. 必背的内容要真的背下来 ★
      · OSPF LSA 类型表（1/2/3/4/5/7）
      · BGP 选路 11 步（至少前 8 步）
      · AD 值表（0/1/20/90/110/120/200）
      · DSCP 值（EF=46、AF41=34、AF21=18）
      · 端口号（179 BGP、500/4500 IPsec、1812 RADIUS、49 TACACS+）
      · CAPWAP 5246/5247
      ★ 这些是"送分题"，背不下来就是白丢分 ★
   
   ★ 3. 不要背题库 ★
      · Cisco 会定期更新题目
      · 背题库过了也不会用
      · ★ 而且违反考试协议，被查到会取消所有认证 ★
```

### ★ 最容易丢分的领域

| 领域 | 为什么容易丢分 | 对策 |
|:--|:--|:--|
| **自动化（15%）** | 传统网工不熟 Python/JSON/YANG | **重点补**，这是最容易拉开差距的地方 |
| **无线（~10%）** | 概念多，实验环境难搭 | 至少把 CAPWAP、漫游、RRM 理解透 |
| **SD-WAN/SD-Access** | 概念抽象 | 记住四大组件和三个平面 |
| **QoS** | 参数多，容易混 | 记住 DSCP 值 + LLQ 原理 |
| **组播** | 平时用得少 | 记住 RPF、PIM-SM、(*,G)/(S,G) |

### 考前一周

```
   □ 刷完本教程所有章节的自测题
   □ 默写：LSA 类型表、BGP 选路顺序、AD 值表、DSCP 值
   □ 重做 Lab 04（OSPF）、Lab 06（BGP）、Lab 07（重分发）
   □ 通读 03-易错点与考试陷阱.md 两遍
   □ 熟悉考试中心的位置和流程
   □ 准备两张有效证件（考试要求）
```

### 考试当天

```
   □ 提前 30 分钟到场
   □ 带两张有效证件（身份证 + 银行卡/护照/驾照）
   □ 不能带任何东西进考场（手机、纸笔都不行，考场提供白板）
   □ ★ 先做完所有选择题，标记不确定的 ★
   □ ★ Sim/Lab 题要留足时间（每题 10-15 分钟）★
   □ ★ Cisco 考试【不能回退】上一题 ★（做完就不能改）
   □ 不确定的题也要选，不倒扣分
```

> ⚠️ **★ Cisco 考试不能回退！** 点了"下一题"就无法返回。**所以每一题都要想清楚再提交。**

## 考后

**通过后**：
1. 登录 [Cisco Certification Tracker](https://cp.certmetrics.com/cisco/) 确认成绩
2. 下载电子证书（约 3-5 天后可用）
3. 更新简历和 LinkedIn
4. **申请 Cisco 认证徽章**（Credly）

**没通过**：
1. **考完立刻记下印象深的题目方向**（不是题目本身，是知识点）
2. 对照成绩单的各域得分，找出薄弱环节
3. 针对性补强 2-3 周
4. 等待 5 天后重考

## 认证维持

**CCNP 有效期 3 年。** 三种续证方式：

| 方式 | 说明 |
|:--|:--|
| **重考** | 重新通过 ENCOR 或任一 Professional 级考试 |
| **考更高级** | 通过 CCIE 笔试 |
| **★ CE 学分 ★** | 通过 Cisco Continuing Education 积累 **80 学分** |

**CE 学分的获取**：在线课程、Cisco Live 会议、作者/讲师贡献等。**推荐这个方式**，比重考轻松。
