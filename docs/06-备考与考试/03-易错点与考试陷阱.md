# 03 · 易错点与考试陷阱

> **考前必读，读两遍。**
> 这里汇总的都是**高频失分点**——不是难，是容易混、容易漏、容易想当然。

---

## ① ★ 方向搞反的（最高频）★

| 概念 | 规则 | ★ 容易记反成 |
|:--|:--|:--|
| **STP 根桥选举** | **优先级小的赢**，MAC 小的赢 | 大的赢 |
| **OSPF DR 选举** | **优先级大的赢**，Router ID 大的赢 | 小的赢 |
| **HSRP/VRRP** | **优先级大的赢** | 小的赢 |
| **管理距离 AD** | **小的更可信** | 大的 |
| **OSPF Cost** | **小的更优** | 大的 |
| **BGP LOCAL_PREF** | **大的更优** | 小的 |
| **BGP MED** | **小的更优** | 大的 |
| **BGP WEIGHT** | **大的更优** | 小的 |
| **BGP AS-Path** | **短的更优** | 长的 |
| **Syslog 级别** | **数字小的更严重**（0=Emergency） | 大的严重 |
| **EIGRP metric** | **小的更优** | — |
| **NTP Stratum** | **小的更权威** | — |

**★ 记忆锚点**：
```
   ★ STP 一族："小的赢"（根桥、根口、指定口都比小）
   ★ OSPF DR / HSRP / VRRP / GLBP："大的赢"
   ★ BGP："Local_Pref 和 Weight 大的赢，MED 和 AS-Path 小/短的赢"
```

## ② ★ 状态名称反直觉的 ★

| 协议 | 状态 | ★ 真实含义 ★ |
|:--|:--|:--|
| **EIGRP** | **Passive (P)** | ✅ **正常**！路由稳定 |
| **EIGRP** | **Active (A)** | ❌ **异常**！正在查询，路由不可用 |
| **BGP** | **Active** | ❌ **异常**！TCP 建立失败，正在重试 |
| **BGP** | **Established** | ✅ 正常 |
| **OSPF** | **2-WAY** | ⚠️ **在广播网上是正常的**（DROTHER 之间） |
| **OSPF** | **FULL** | ✅ 正常 |

**★ 考点原句**：
> "路由器 A 的 EIGRP 拓扑表显示某路由处于 **Active** 状态，这说明什么？"
> → **说明它正在查询新路径，路由暂时不可用**（不是"活跃正常"）

## ③ ★ 容易漏配的关键命令 ★

| 场景 | ★ 必配但容易漏 ★ | 漏了的后果 |
|:--|:--|:--|
| **三层交换机做 VLAN 间路由** | ★ `ip routing` ★ | 同 VLAN 通，**跨 VLAN 全不通**（且 SVI 和路由表看起来都正常） |
| **重分发进 OSPF** | ★ `subnets` ★ | **只重分发主类网络**，子网全丢 |
| **重分发进 EIGRP/RIP** | ★ `metric` 或 `default-metric` ★ | metric 无穷大，**路由不可用** |
| **EIGRP（老版本）** | ★ `no auto-summary` ★ | 自动汇总到主类，**路由环路/黑洞** |
| **HSRP** | ★ `preempt` ★ | 优先级高也不抢占，**故障恢复后不切回** |
| **HSRP** | ★ `track` ★ | **上行断了不切换**，流量进黑洞 |
| **iBGP** | ★ `next-hop-self` ★ | 路由 **inaccessible**，不进路由表 |
| **iBGP 用 Loopback** | ★ `update-source Loopback0` ★ | 邻居建不起来（Active） |
| **eBGP 用 Loopback** | ★ `ebgp-multihop` ★ | TTL=1 不够，邻居建不起来 |
| **BGP Community 策略** | ★ `send-community` ★ | Community 属性不发送，**策略失效** |
| **MP-BGP (L3VPN)** | ★ `activate` + `send-community both` ★ | VPNv4 路由收不到 |
| **DHCP 跨网段** | ★ `ip helper-address` ★ | 客户端拿 169.254.x.x |
| **DHCP Snooping** | ★ 上联口 `trust` ★ | **全网拿不到 IP** |
| **DAI/IPSG** | ★ 静态设备手工绑定 ★ | 服务器/打印机全部断网 |
| **NAT** | ★ `ip nat inside/outside` ★ | NAT 完全不工作 |
| **NAT + VPN** | ★ ACL 里 `deny` 去对端的流量 ★ | 隧道 UP 但内网不通 |
| **隧道（GRE/IPsec）** | ★ `ip mtu` + `ip tcp adjust-mss` ★ | 小包通大包不通 |
| **MPLS/VXLAN** | ★ 全路径加大 MTU ★ | 同上 |
| **DMVPN + EIGRP** | ★ `no ip split-horizon eigrp` ★ | Spoke 之间学不到路由 |
| **DMVPN + mGRE + IPsec** | ★ `shared` 关键字 ★ | SA 冲突 |
| **AAA** | ★ `local` 保底 ★ | 服务器不可达时**登不上设备** |
| **802.1X** | ★ Critical Auth ★ | RADIUS 挂了**全公司断网** |
| **route-map / ACL / prefix-list** | ★ 兜底的 `permit` ★ | 隐含 deny 拦掉一切 |
| **H3C/华为 MST** | ★ `active region-configuration` ★ | Region 配置不生效 |
| **OSPF（现代网络）** | ★ `auto-cost reference-bandwidth` ★ | 千兆万兆 cost 都是 1 |

## ④ ★ 覆盖 vs 追加 ★

| 命令 | 行为 | ★ 危险 |
|:--|:--|:--|
| `switchport trunk allowed vlan 10` | ★ **覆盖** ★（只剩 VLAN 10） | ★★ **整栋楼断网** |
| `switchport trunk allowed vlan **add** 10` | 追加 | ✅ 安全 |
| `switchport trunk allowed vlan **remove** 10` | 移除 | — |
| `switchport trunk allowed vlan all` | 全放行 | — |
| `switchport trunk allowed vlan except 999` | 除了 999 全放行 | — |

**★ 这是运维事故排行榜 Top 3 的命令。**

**同样的陷阱**：
```cisco
! MST 的 VLAN 映射也是覆盖
spanning-tree mst configuration
 instance 1 vlan 10        ← 覆盖！之前映射到实例 1 的 VLAN 全没了
 instance 1 vlan 10,20     ← 要写全
```

## ⑤ ★ 隐含 deny 的四个地方 ★

```
   ★ ACL ★                  末尾隐含 deny any
   ★ route-map ★            末尾隐含 deny
   ★ prefix-list ★          末尾隐含 deny
   ★ as-path access-list ★  末尾隐含 deny
```

**★ 必须加兜底**：
```cisco
! ACL
ip access-list extended MY-ACL
 permit tcp any host 10.0.0.1 eq 80
 ★ permit ip any any ★              ← 或明确的 deny + log

! route-map
route-map MY-POLICY permit 10
 match ip address prefix-list X
 set local-preference 200
★ route-map MY-POLICY permit 20 ★    ← 空 permit = 兜底

! prefix-list
ip prefix-list MY-LIST seq 5 deny 10.0.0.0/8 le 32
★ ip prefix-list MY-LIST seq 10 permit 0.0.0.0/0 le 32 ★

! as-path
ip as-path access-list 1 deny _300_
★ ip as-path access-list 1 permit .* ★
```

**★ 例外：PBR 的 route-map 语义不同**
```
   在 PBR 中：
   · 不匹配任何语句的流量 → ★ 走正常路由表（不是丢弃）★
   · 匹配 deny 语句的流量 → ★ 也走正常路由表 ★
   
   所以 PBR 里的 deny 是"不做策略路由"，不是"丢弃"
```

## ⑥ ★ prefix-list 的 `le 32` 陷阱 ★

| 写法 | ★ 匹配什么 ★ |
|:--|:--|
| `permit 0.0.0.0/0` | ★ **只匹配默认路由** ★ |
| `permit 0.0.0.0/0 le 32` | ★ **匹配所有前缀** ★ |
| `permit 10.0.0.0/8` | 只匹配 10.0.0.0/8 本身 |
| `permit 10.0.0.0/8 le 32` | 10.0.0.0/8 及其所有子网 |
| `permit 10.0.0.0/8 ge 24` | 10.0.0.0/8 内长度 ≥24 的 |
| `permit 10.0.0.0/8 ge 24 le 24` | 10.0.0.0/8 内**正好 /24** 的 |

**★ 最常见的错误**：想"放行所有路由"却写了 `permit 0.0.0.0/0`，结果只放行了默认路由，其他全被隐含 deny 拦掉。

## ⑨ ★ OSPF 专项易错 ★

### LSA 类型表（★★ 必须能默写 ★★）

| Type | 名称 | **谁产生** | **传播范围** | 标记 |
|:--|:--|:--|:--|:--|
| **1** | Router | **每台路由器** | **本区域** | `O` |
| **2** | Network | **DR** | **本区域** | `O` |
| **3** | Summary | **ABR** | **跨区域** | `O IA` |
| **4** | ASBR Summary | **ABR** | 跨区域 | — |
| **5** | AS External | **ASBR** | **整个 AS** | `O E1/E2` |
| **7** | NSSA External | NSSA 内的 ASBR | **仅 NSSA** | `O N1/N2` |

### 特殊区域（★★ 必须能默写 ★★）

| 区域 | Type-3 | Type-4/5 | Type-7 | 默认路由 |
|:--|:--|:--|:--|:--|
| 标准 | ✅ | ✅ | ❌ | ❌ |
| **Stub** | ✅ | ❌ | ❌ | ✅ 自动 |
| **Totally Stub** | ❌ | ❌ | ❌ | ✅ 自动 |
| **NSSA** | ✅ | ❌ | ✅ | ⚠️ **需手工** |
| **Totally NSSA** | ❌ | ❌ | ✅ | ✅ 自动 |

**★ 配置要点**：
```
   ★ Stub/NSSA 标志：区域内【所有】路由器都要配 ★
   ★ no-summary：【只在 ABR】上配 ★
   ★ NSSA 不自动注入默认路由，需 default-information-originate ★
```

### 其他 OSPF 易错

| 易错点 | 正确答案 |
|:--|:--|
| 邻居卡 **EXSTART** | ★ **MTU 不匹配**（99%） |
| 邻居卡 **INIT** | 对方收不到我的 Hello（ACL 拦组播、单向链路） |
| 停在 **2-WAY** | ★ **DROTHER 之间是正常的** |
| 建邻居的 5 个条件 | ★ Area / Hello&Dead / 认证 / **Stub标志** / 掩码 |
| MTU 在不在 Hello 里 | ❌ **不在**（所以不影响 Hello，但卡 ExStart） |
| **E1 vs E2** | ★ E1 = 外部+内部 cost；E2 = 只算外部（**默认**） |
| E1 和 E2 谁优先 | ★ **E1 永远优于 E2**（无论 metric） |
| OSPF 路由优先级 | ★ **Intra > Inter > E1 > E2** |
| `area range` vs `summary-address` | ★ range 在 **ABR**（Type-3）；summary-address 在 **ASBR**（Type-5） |
| 虚链路的穿越区域 | ★ **不能是 Stub/NSSA** |
| 参考带宽 | ★ 默认 100Mbps，**必须全网统一修改** |
| P2P 网络类型 | ★ 不选 DR，**不产生 Type-2 LSA** |
| `distribute-list in` | ★ **只过滤路由表，不影响 LSDB** |

## ⑩ ★ BGP 专项易错 ★

### 选路 11 步（★★ 必背前 8 步 ★★）

```
   ★ We Love Oranges As Apples, Mmm, Eat In Rome ★
   
   ① WEIGHT           大的赢（Cisco 私有，只本机）
   ★② LOCAL_PREF ★    大的赢（AS 内传播）
   ③ 本地产生的
   ★④ AS_PATH 长度 ★  短的赢
   ⑤ ORIGIN           i > e > ?
   ⑥ MED              小的赢
   ⑦ eBGP > iBGP
   ⑧ IGP metric       小的赢
   ⑨ 更老的 eBGP
   ⑩ Router ID 小
   ⑪ 邻居 IP 小
```

### 其他 BGP 易错

| 易错点 | 正确答案 |
|:--|:--|
| **Active 状态** | ❌ **TCP 建立失败，正在重试**（不是正常） |
| **iBGP 水平分割** | ★ 从 iBGP 学到的**不能再传给其他 iBGP** |
| iBGP 全互联的替代 | ★ **RR** 或 Confederation |
| **RR 防环属性** | ★ **ORIGINATOR_ID** + **CLUSTER_LIST** |
| **iBGP 的 NEXT_HOP** | ★ **不变**（所以要 `next-hop-self`） |
| eBGP 的 NEXT_HOP | 改成自己 |
| **`network` 命令** | ★ 要求路由表有**完全匹配**的路由 |
| **`r` 标记** | ★ **RIB-failure**（有 AD 更低的路由抢赢了） |
| **只有 `*` 没有 `>`** | 不是最优路径 |
| **什么标记都没有** | ★ **下一跳不可达** |
| `s` 标记 | suppressed（被聚合抑制） |
| **控出向流量** | ★ **LOCAL_PREF** |
| **控入向流量** | ★ **AS-Path Prepend**（MED 不可靠） |
| **`as-set` 的作用** | ★ 保留被聚合路由的 AS_PATH，**防环** |
| eBGP 默认 TTL | ★ **1**（用 Loopback 要 `ebgp-multihop`） |
| 软重置 | ★ `clear ip bgp X **soft** in/out`（**绝不用 `clear ip bgp *`**） |

## ⑪ ★ EIGRP 专项易错 ★

| 易错点 | 正确答案 |
|:--|:--|
| **可行性条件 FC** | ★ **邻居的 RD < 我的 FD**（严格小于） |
| **FD** | 我到目标的总距离 |
| **RD** | 邻居报告的它到目标的距离 |
| **Passive/Active** | ★ **Passive 正常，Active 异常** |
| **SIA 的成因** | ★ 查询扩散范围太大 + 有邻居不回 REPLY |
| **防 SIA 最有效的手段** | ★ **路由汇总**（建立查询边界）+ **Stub** |
| **EIGRP 汇总路由的 AD** | ★ **5**（不是 90！） |
| EIGRP 外部路由 AD | 170 |
| **建邻居的条件** | ★ AS 号 + K 值 + 同子网 + 认证（**Hello/Hold 不需要匹配**） |
| **MTU 检查** | ★ EIGRP **不检查**（OSPF 才检查） |
| **不等价负载均衡** | ★ `variance`，**只有 FS 能参与** |
| `no auto-summary` | ★ 老版本默认开启，必须关 |
| Stub 的限制 | ★ **不能做中转**（只有真正的末梢能配） |
| DMVPN 上的 EIGRP | ★ `no ip split-horizon eigrp` |

## ⑫ ★ 概念混淆对 ★

| 概念 A | 概念 B | ★ 区别 |
|:--|:--|:--|
| **RD**（Route Distinguisher） | **RT**（Route Target） | RD 让地址**唯一**；RT 控制**导入导出**（决定拓扑） |
| **`ip mtu`** | **`ip tcp adjust-mss`** | 前者管**所有流量**（被动）；后者**只管 TCP**（主动改 MSS） |
| **整形 Shaping** | **监管 Policing** | 整形**缓存排队**；监管**直接丢弃** |
| **NETCONF** | **RESTCONF** | SSH **830** + XML + **事务**；HTTPS **443** + JSON |
| **北向接口** | **南向接口** | 北向 = 面向**应用**（REST）；南向 = 面向**设备**（NETCONF） |
| **TACACS+** | **RADIUS** | TCP49/**加密全部**/**支持命令授权**；UDP1812/只加密密码 |
| **Root Guard** | **Loop Guard** | Root 防"**外来的更好**"；Loop 防"**该来的没来**" |
| **DHCP Snooping trust** | untrust | trust 允许 OFFER/ACK；untrust 只允许 DISCOVER/REQUEST |
| **Phase 2 DMVPN** | **Phase 3** | P2 **不能汇总**；P3 用 Redirect+Shortcut **能汇总** |
| **LOCAL_PREF** | **WEIGHT** | LP 影响**整个 AS**；Weight **只本机**（Cisco 私有） |
| **PIM-DM** | **PIM-SM** | DM 是**推**（先泛洪）；SM 是**拉**（需 RP） |
| **(\*, G)** | **(S, G)** | 共享树（RP 为根）；最短路径树（源为根） |
| **`established`** | **自反 ACL** | 前者只看 ACK 位（伪状态）；后者**真状态跟踪**，支持 UDP |
| **VLAN** | **VRF** | VLAN 隔离**广播域**（二层）；VRF 隔离**路由表**（三层） |
| **SPAN** | **NetFlow** | SPAN 抓**完整包**；NetFlow 只记**流的元数据** |
| **MDT（Telemetry）** | **SNMP** | MDT 是**推**（秒级）；SNMP 是**拉**（分钟级） |
| **strict uRPF** | **loose uRPF** | strict 要求**出接口匹配**；loose 只要**有路由** |

## ⑭ ★ 命令语法陷阱 ★

```cisco
! ── ① 通配符掩码 vs 子网掩码 ──
access-list 10 permit 192.168.1.0 ★ 0.0.0.255 ★     ← ACL 用【通配符】
ip route 192.168.1.0 ★ 255.255.255.0 ★ 10.0.0.1     ← 静态路由用【子网掩码】
network 192.168.1.0 ★ 0.0.0.255 ★ area 0            ← OSPF 用【通配符】
network 192.168.1.0 ★ 0.0.0.255 ★                   ← EIGRP 用【通配符】
network 192.168.1.0 ★ mask 255.255.255.0 ★          ← ★ BGP 用【子网掩码】★

! ── ② access-class vs access-group ──
line vty 0 15
 ★ access-class ★ MGMT in            ← VTY 用 access-class
interface Gi0/1
 ★ ip access-group ★ MY-ACL in       ← 接口用 access-group

! ── ③ 隧道保护 vs crypto map ──
interface Tunnel0
 ★ tunnel protection ipsec profile PROF ★    ← 现代方式（不需要感兴趣流 ACL）
interface Gi0/1
 ★ crypto map MYMAP ★                        ← 传统方式（需要 ACL）

! ── ④ EIGRP 的 no ip split-horizon 要带 AS 号 ──
interface Tunnel0
 ★ no ip split-horizon eigrp 100 ★   ← EIGRP 要 AS 号
 ★ no ip split-horizon ★             ← RIP 不要

! ── ⑤ 虚链路的参数是 Router ID，不是 IP ──
router ospf 1
 ★ area 1 virtual-link 2.2.2.2 ★     ← 对端的 Router ID

! ── ⑥ 优先级必须是 4096 的倍数（STP）──
spanning-tree vlan 10 priority ★ 4096 ★   ✓
spanning-tree vlan 10 priority 4000       ✗ 报错
```


**能说清下面十个"为什么"，你就真懂了**：

```
   □ 1. 为什么二层环路比三层环路可怕？（★ 没有 TTL）
   □ 2. 为什么 OSPF 卡在 ExStart 通常是 MTU？（★ DD 报文按接口 MTU 构造）
   □ 3. 为什么 iBGP 需要 next-hop-self？（★ iBGP 不改下一跳）
   □ 4. 为什么双点双向重分发会环路？（★ 重分发丢失了路由的"血统"）
   □ 5. 为什么 EIGRP 的可行性条件能防环？（★ RD<FD 意味着不经过我）
   □ 6. 为什么 Phase 2 DMVPN 不能汇总？（★ 汇总后下一跳变成 Hub）
   □ 7. 为什么 LLQ 的优先队列要有上限？（★ 防止饿死其他业务）
   □ 8. 为什么 VXLAN 的 VNI 是 24 位？（★ VLAN 4094 个不够）
   □ 9. 为什么 SD-Access 要用 LISP？（★ 身份与位置分离，移动时 IP 不变）
   □ 10. 为什么"接口 up"不等于"链路可用"？（★ 远端故障本地不感知）
```
