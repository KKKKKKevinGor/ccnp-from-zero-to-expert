## ★ 自查方法

**用这个表做三轮自查**：

```
   ★ 第一轮（学习中）★
      每学完一章，回来勾掉对应的考纲项
      → 确保没有遗漏
   
   ★ 第二轮（学完全部）★
      逐条问自己："这一项我能讲清楚吗？能配置吗？能排障吗？"
      → 三个都能才打勾
      → 有一个不能，回去重看那一节 + 做实验
   
   ★ 第三轮（考前一周）★
      只看没打勾的和打勾但不自信的
      → 集中突破
```

**★ 掌握程度的三级标准**：

| 级别 | 标准 |
|:--|:--|
| **能讲** | 能向别人解释这是什么、解决什么问题、原理是什么 |
| **能配** | 不看文档能写出配置命令 |
| **★ 能排障 ★** | 给你一个故障现象，能说出排查思路和验证命令 |

**★ 只有三个都达到，才算真的掌握。** 考试里 Sim/Lab 题考"能配"，选择题大量考"能排障"。
